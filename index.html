        Update WeaveMap safely

        Your project data lives in weavemap/state.js. A runtime update must never replace it with the blank template.

        1. Back up weavemap/state.js.
        2. Replace only PROTOCOL.md, index.html, app.js, style.css, generate_hud.mjs, and generate_hud.ps1.
        3. Read the new protocol and migrate state only if the schema changed.
        4. Validate before deleting the backup.

        Never overwrite state.js during a runtime update.
