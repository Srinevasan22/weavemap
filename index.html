        Update WeaveMap safely

        Your project data lives in weavemap/state.js. A runtime update must never replace that file with the blank template from the WeaveMap repository.

        1. Make a temporary backup of weavemap/state.js.
        2. Replace only PROTOCOL.md, index.html, app.js, and style.css from the latest WeaveMap repository.
        3. Read the new protocol and migrate the existing state.js in place only if the state schema changed.
        4. Open the observer and resolve any validation errors before deleting the temporary backup.

        Never overwrite state.js during a runtime update. It contains your tasks, status, notes, evidence, requirements, decisions, adoption baseline, and agent history.
